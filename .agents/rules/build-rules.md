# Build Rules — MeMo

## 1. Deployment Target

* Minimum macOS: `11.0`. Must match `LSMinimumSystemVersion` in `Info.plist`.
* Do not lower the deployment target — it will break APIs already in use.
* The `-target arm64-apple-macosx11.0` flag bakes `minos` into the binary via `LC_BUILD_VERSION`.

## 2. SDK Path

* Active SDK: `/Library/Developer/CommandLineTools/SDKs/MacOSX15.5.sdk`
* Hardcoded in `build.sh` with a fallback to `xcrun --show-sdk-path` if the path does not exist.
* Do not change the SDK path without checking `swift --version` compatibility first.
* To list available SDKs: `ls /Library/Developer/CommandLineTools/SDKs/`

## 3. Compiler Flags — Do Not Remove

```
-Osize       size-optimized compilation (smaller binary)
-wmo         whole module optimization (enables cross-file inlining)
-dead_strip  (via -Xlinker) removes unused symbols at link time
```

Removing any of these flags increases binary size and degrades performance.

## 4. Binary & Architecture

* Build target: `arm64` only (Apple Silicon). Universal binary was removed intentionally.
* Output: `MeMo.app/Contents/MacOS/MeMo`
* After build, binary is stripped with `strip -x` to remove local symbols.
* App bundle is ad-hoc signed with `codesign --force --sign -`.

## 5. Sources List

These files are compiled in order:
```
SMC.swift  StatsEngine.swift  Formatters.swift  StatusBarView.swift  AppSettings.swift
LoginItemService.swift  MenuFactory.swift  AppDelegate.swift  main.swift  Version.swift
```
`Version.swift` is auto-generated by `build.sh` — never hand-edit it.

## 6. Post-Build Verification

After every build, run:
```bash
bash .agents/hooks/post-build.sh
```
This verifies binary exists, reports size, architecture, and code signature, and appends to `build_history.log`.
