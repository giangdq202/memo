# AGENTS.md - MeMo (Personal Fork)

Single source of truth for all agents. CLAUDE.md and GEMINI.md only point here.

MeMo is a macOS menu bar monitor (CPU / RAM / temperature / top processes). Pure Swift 5.x + AppKit, no Xcode, no dependencies, Apple Silicon only, min macOS 11.0. Fork of openhoangnc/mac-stats (MIT). Owner is learning Swift through this project.

## Workflow (tiered)

Trivial (typo, docs, comment, one-line obvious fix):
`BRANCH -> EDIT -> BUILD -> COMMIT -> PR`. No grilling.

Normal (bug fix, small feature, refactor):
`BRIEF PLAN (3-5 lines, confirm) -> BRANCH -> IMPLEMENT -> BUILD -> TEST -> COMMIT -> MEMORY -> PR`

Large (new feature, architecture, anything touching a critical file):
`GRILL (one question at a time) -> PLAN (get approval) -> BRANCH -> IMPLEMENT in small steps -> BUILD -> TEST -> COMMIT -> MEMORY -> PR`

Rules for all tiers:
* Never commit to `main`. Branch from fresh `main`: `feat/`, `fix/`, `refactor/`, `docs/`, `chore/`.
* Conventional Commits, English, one logical change per commit.
* Build with `bash build.sh` after every Swift change. It must pass before commit.
* Update `.agents/memory/` in the same branch, as part of the final commit of the change (not after the PR).
* Merge only via PR, squash: `gh pr merge --squash --delete-branch`.

## Stop and ask first

* Any edit to `SMC.swift` (low-level IOKit). Pre-commit blocks it unless `ALLOW_SMC=1`.
* `Info.plist`, especially `LSUIElement` and `CFBundleIdentifier`.
* `build.sh`: SDK path, `-Osize -wmo -dead_strip`, deployment target.
* Renaming or deleting a UserDefaults key (silently loses user settings).
* Adding a dependency, importing SwiftUI, adding an `.xcodeproj`.
* Running `install.sh` / `uninstall.sh`, or writing outside the project folder.
* `rm -rf` anywhere other than what `build.sh` already does to `MeMo.app`.

Details: `.agents/rules/critical-change-guard.md`.

## Build

```bash
bash build.sh        # arm64 build -> MeMo.app
open MeMo.app
scripts/smoke-test.sh
scripts/policy-check.sh
```

Run `scripts/install-hooks.sh` once per clone to enable the pre-commit policy check.

## Layout

```
main.swift          entry point, CLI flags, single-instance guard
AppDelegate.swift   lifecycle, timer, menus, settings, alerts
StatsEngine.swift   CPU / RAM / temperature / top-process sampling
StatusBarView.swift menu bar drawing, color and format helpers
SMC.swift           IOKit/SMC access - DO NOT MODIFY
Version.swift       generated by build.sh - never edit, never commit
scripts/            smoke-test.sh, policy-check.sh, install-hooks.sh
.agents/            rules, skills, hooks, memory
```

## Coding standards (short)

* Swift 5.x semantics, no strict concurrency. `guard let` when nil is an exit path.
* No `as!` / force unwrap on user input or `representedObject`.
* No allocations in `draw()` or timer callbacks. Every C allocation has a matching free.
* `[weak self]` in closures. Doc comment on every new function. `// MARK: -` sections.
* Colors: system or `calibratedHue` with `isDark`; never hardcoded RGB.
* Settings: computed property over `UserDefaults`, conservative default.
Full text: `.agents/rules/swift-coding-standards.md`.

## UserDefaults keys

Every key used in code must appear here (checked by `scripts/policy-check.sh`).

* `updateInterval` (Double seconds: 0.25, 0.5, 1.0, 2.0, 5.0; default 2.0)
* `tempUnit` (String "C" or "F"; default "C")
* `showCPUTemperature` (Bool; default true)
* `LaunchAtLogin` (Bool; default false)
* `cpuAlertThreshold` (Double, 0 = off; presets 60/70/80/90/95; default 0)
* `ramAlertThreshold` (Double, 0 = off; presets 70/80/85/90/95; default 0)
* `tempAlertThreshold` (Double, 0 = off; presets 70/80/90/100; default 0)
* `sparklineMetric` (String "", "cpu", "ram", "temp"; default "")

## Skills

`.agents/skills/` holds task playbooks. Use `add-menu-setting` for any new setting, `remove-feature` for deleting a feature, `debug-and-fix` for build/runtime failures, `git-workflow` for branch/PR mechanics.

## Definition of done

1. `bash build.sh` clean, `scripts/smoke-test.sh` and `scripts/policy-check.sh` pass.
2. App launches and the feature works in both Dark and Light mode.
3. Settings persist after quit and reopen.
4. Memory updated, docs and UserDefaults list in sync.
5. PR squash-merged into `main`.
